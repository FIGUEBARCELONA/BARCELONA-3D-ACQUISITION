GHCNh VERSION UPDATE: From v1.0.1 (previous) to v1.1.0 (new)

March 10, 2026

Changes from previous version:

1) New variables added (19 cloud/sky and 2 high-resolution precipitation elements)
2) Some sky variables were removed and replaced
3) Some data abbreviations, measurement codes, and report type codes have been changed
4) Header/column changes
